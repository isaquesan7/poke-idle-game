# ONLINE-01C-23E18 — candidato de gateway autenticado separado

## Decisão candidata e limites
O teste real #259 mostrou que cabeçalhos X-Real-IP/X-Railway-Edge são falsificáveis por serviço privado. Não assinar no web atual. Railway documenta isolamento de rede privada por projeto/ambiente (https://docs.railway.com/networking/private-networking/how-it-works); X-Real-IP é metadado do ingress público (https://docs.railway.com/networking/public-networking/specs-and-limits). Candidato: gateway em projeto/ambiente exclusivo, sem serviços irmãos, DB, plugins de terceiros ou destinos arbitrários; recebe HTTPS público, resolve identidade SOMENTE mediante adapter de ingress previamente validado; assina requisição com chave dedicada; encaminha por HTTPS ao web fixo; web sem chave de emissão, apenas transporta assertion; API valida HMAC, corpo, rota, tempo e nonce distribuído. Acesso direto ao web/API sem prova válida deve falhar. Não se presume isolamento absoluto apenas por configuração de projeto: comprovar ausência de rota privada cruzada, exposição alternativa/TCP proxy e spoofing em gateway isolado, inventário e controle de mudanças (qualquer novo serviço reabre revisão). A chave HMAC de verificação continua simétrica.

## Implementado somente em CI
scripts/auth-gateway-candidate.mjs: cinco rotas POST exatas, origem fixa, upstream HTTPS Railway fixado (HTTP loopback exclusivamente NODE_ENV=test), 16 KiB e prazo, allowlist de resposta, sem redirects, não copia cabeçalhos de prova fornecidos pelo navegador. Requer resolver injetado; NÃO inclui adapter Railway ativo ou launcher. online-api-proxy.mjs encaminha prova única apenas com NODE_ENV=test + ONLINE_GATEWAY_FORWARD_TEST_ONLY=true + upstream loopback; rejeita falta/duplicidade/query e não assina. Produção continua descartando prova externa. Teste real de três listeners locais com emissor/receptor canônicos e stub nonce verifica prova forjada direta, identidade independente de headers externos, reuso/adulteração, origem, tamanho, rota, cookie/allowlist. Stub não substitui PG18, já testado separadamente #256; próximo conectar os três hops ao PG real.
