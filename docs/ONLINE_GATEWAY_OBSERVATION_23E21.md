# ONLINE-01C-23E21 — imagem de homologação isolada do ingress do gateway

A imagem Dockerfile.gateway-observation contém três arquivos, Node sem dependências, usuário node. Não executa gateway de contas, não encaminha requests, não aceita chave de produção, não retorna IP, subject, assertion, token ou corpo de usuário. Usa segredo aleatório em memória para verificar assinatura de corpo sintético fixo e responde booleanos. Token temporário, GET /probe, limite 60, 15 min. CI loopback comprova que um header falso em acesso direto pode levar a assinatura sintética válida: productionTrustGranted permanece false sempre. Nenhuma decisão de confiança baseada somente em X-Real-IP/X-Railway-Edge.
